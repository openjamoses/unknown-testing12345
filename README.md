## Artifact for Double-Anonymous Review

This repository contains the replication package accompanying the submitted manuscript. It has been prepared for double-anonymous peer review.

The package contains the processed data, analysis outputs, visualizations, regression taxonomy, and mitigation results needed to inspect the empirical findings reported in the manuscript.

Information that could identify the authors has intentionally been omitted during the review period.

## Data Availability

The artifacts included in this repository are provided to support independent inspection and reproduction of the results reported in the submitted manuscript.

The repository has been anonymized for peer review. Identifying information and permanent archival metadata will be added after completion of the review process, where appropriate.

## Contact

To preserve double anonymity, author contact information is intentionally omitted during peer review. Questions concerning the submission should be communicated through the conference review system.
